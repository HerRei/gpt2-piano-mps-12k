01 / THE IDEAA game, then a detour

What if the music
could play along?

A quiet room. A chase. A moment to breathe. I wanted the piano in PhantomHunt to follow what was happening.

The idea came from a friend’s project at MIT. At first, the hardware it seemed to need was completely out of scope. So I started with a smaller question: could I train a model to continue a piano passage?

That became one project, in two chapters.

Aria’s roughly three tokens per note allow about 12 ms per token in the 99th-percentile second.

TOKEN→
STATE↻
→TOKEN

A memory that stays the same size.

RWKV-7 carries a fixed-size state from one token to the next. A GPT carries an attention cache. Moving that cache was costly; keeping it inside the model did not compile for the Neural Engine in my tests.

Speed tests used random weights, batch one, on an M1 Pro. These are model timings, not an in-game benchmark or a judgement of the music. RWKV-7 was measured on 7 October; the REMI budget and GPT CPU result on 4 October.

01 / VOCABULARY

Piano, pared back.

Aria’s tokenizer, trimmed to piano. 2,176 tokens, including 13 control tokens for density and loudness. A much larger dataset than MAESTRO’s few million tokens.

02 / CONDITIONING

Music with instructions.

Every five seconds, controls describe the coming music: eight density levels and five loudness levels. Dropping controls 15% of the time enables classifier-free guidance.

What guidance did, and what still needs testing +

The small runs compared requested and contrasting controls, running each token step twice. The full recipe adds control dropout for classifier-free guidance. That compares controlled and unconditioned predictions; its strength still needs tuning.

Two passes at 94M would cost about 7 ms per token on the Neural Engine. That is an estimate. It has not been measured as part of the game.

01 What this still can’t do+

v1 / Continuation, with caveats

Quality depends on the prompt and checkpoint. MAESTRO is small and stylistically narrow. My random file split can put related pieces on both sides, flattering validation loss. The demo is a selected sample. The intensity editor is experimental and not a note-preserving live editor.

v2 / A player needs a conductor

Continuous notes do not make long-form structure. The game needs a conductor to bring themes back and set controls. Listening tests and the full game loop are still ahead. Both versions take musical context, not text prompts.

03 Run v1 locally+

Training and generation need your own local data and checkpoint. Start with the dependency smoke check: 

python3 -m pip install -r requirements-smoke.txt
python3 -m unittest tests.test_dependency_smoke

Then prepare, train, and generate:

python3 scripts/prepare_12k_split.py
python3 scripts/augment_train_transpose.py
python3 scripts/tokenize_12k_augmented.py
python3 scripts/train_gpt2_piano_12k.py --train-from-scratch
python3 scripts/generate_piano_sample.py --checkpoint checkpoints/best
